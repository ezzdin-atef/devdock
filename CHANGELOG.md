# Changelog

All notable changes to DevDock. Versions follow [semver](https://semver.org).

## [0.3.0] - 2026-11-17

### Added

- Light theme, following Windows or chosen in Settings; theme toggle in the title bar.
- Custom title bar with breadcrumb and window controls.
- Redesigned logo and app icon.
- In-app updates from GitHub Releases.
- Per-machine installer (Program Files) with DevDock branding.
